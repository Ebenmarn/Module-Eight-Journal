# Module-Eight-Journal

Driverpass project is a system to allow students to have better driver training so the may pass the DMV tests. The client is the owner who wants use to build a web interface allowing students to take online classes and tests  as well as schedule in-person driving.

I did great for the business requirement doc. I was able to list what the business will need, but I failed in system design document. I would if I could re make the UML diagrams so that they better encompass what is there and for better understanding. 
A system is meant for users to use it. By making user use cases you think of how a user would interact with the system. This allows us to think of all the different requirements needed to ensure the user is able to do what they want as well as seeing where there is vulnerabilities in the design.

I will do software design in an iterative way. Making requirement documentation, designing use cases, and then system diagrams. Once the software is all thought out, I will then begin building the system. Agile methodology and prtotyping is important for analyzing and design.
